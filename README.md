# image_picker

Консольное приложение на Rust, которое рекурсивно сканирует директорию, выводит список найденных изображений, отсортированный по имени папки, а затем по имени файла (по возрастанию), и открывает выбранное по номеру в программе просмотра по умолчанию.

Приложение не использует внешние зависимости, только стандартную библиотеку.

## Возможности

- Рекурсивный обход директории (симлинки не разворачиваются, поэтому циклы исключены).
- Фильтрация по расширению: `jpg`, `jpeg`, `png`, `gif`, `bmp`, `webp`, `tif`, `tiff`, `ico`, `svg` (задается константой, регистр не важен).
- Сортировка по пути: сначала по имени папки, затем по имени файла, по возрастанию. Сравнение «естественное»: числа учитываются по значению, поэтому папка `2` идёт перед `10` (при обычной текстовой сортировке было бы наоборот). Регистр букв не важен.
- В списке рядом с каждым файлом показывается дата изменения (информационно, на порядок не влияет).
- Интерактивный выбор: можно открывать несколько изображений подряд, не перезапуская программу.
- Кроссплатформенное открытие файлов: Windows, macOS, Linux.

## Требования

- [Rust](https://www.rust-lang.org/tools/install) (edition 2021, любая актуальная версия stable).
- На Linux: установленный `xdg-open` (входит в пакет `xdg-utils`) и настроенная программа просмотра изображений по умолчанию.

## Сборка и запуск

```bash
# Сканировать указанную директорию
cargo run --release -- /путь/к/папке

# Сканировать текущую директорию
cargo run --release
```

Или собрать исполняемый файл отдельно:

```bash
cargo build --release
./target/release/image_picker /путь/к/папке
```

На Windows бинарник лежит в `target\release\image_picker.exe`.

## Пример работы

```
   1. [2023-04-12 09:15:02] ./1/img_001.jpg
   2. [2023-04-12 09:15:40] ./1/img_002.jpg
   3. [2023-08-30 18:42:11] ./2/img_001.png
   4. [2024-01-05 12:00:47] ./10/img_001.webp

Введите номер (1-4), q или пустая строка — выход: 3
Открываю: ./2/img_001.png

Введите номер (1-4), q или пустая строка — выход: q
```

## Управление

| Ввод                  | Действие                               |
|-----------------------|----------------------------------------|
| Число от 1 до N       | Открыть изображение с этим номером     |
| `q` или пустая строка | Выйти из программы                     |
| Любой другой ввод     | Сообщение об ошибке и повторный запрос |

## Настройка

- **Список расширений** меняется в константе `IMAGE_EXTENSIONS` в `src/main.rs`.
- **Порядок сортировки**: задаётся в `path_cmp` и `natural_cmp` в `src/main.rs`. Чтобы сортировать по дате, замените вызов `files.sort_by(...)` в `main` на `files.sort_by_key(|(_, time)| *time)`.
- **Дата создания вместо даты изменения** (в выводе): замените `m.modified()` на `m.created()` в функции `scan`. На некоторых файловых системах Linux дата создания недоступна.

## Ограничения

- Время в списке отображается в UTC, а не в локальном часовом поясе.
- Файлы, для которых не удалось получить дату изменения, в список не попадают.
- Папки без прав на чтение пропускаются с предупреждением в stderr.
